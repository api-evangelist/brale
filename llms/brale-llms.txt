# Brale

> API documentation for issuing, moving, and managing stablecoins on any blockchain with Brale.

## Docs

- [Brale Issuance and Orchestration API](https://docs.brale.xyz/api-reference/brale-introduction.md): Stablecoin issuance, orchestration, onramps, offramps, and swaps via the Brale API.
- [Archive an Automation](https://docs.brale.xyz/api-reference/brale/archive-automation.md): Archives an automation, permanently stopping it from processing deposits. The underlying virtual account is closed and billing is released.
- [Archive Webhook Subscription](https://docs.brale.xyz/api-reference/brale/archive-webhook-subscription.md): Archive a webhook subscription. Future events will not be delivered to this subscription.
- [Create a customer account](https://docs.brale.xyz/api-reference/brale/create-account.md): Creates a new customer (account) with the required KYC/KYB details.
- [Create a new external address](https://docs.brale.xyz/api-reference/brale/create-address.md): Creates a non-custodial address (EOA) for the specified account using the Direct bank entry path.
- [Create an Automation](https://docs.brale.xyz/api-reference/brale/create-automations.md): Create an automation that mints stablecoins to a destination wallet when fiat deposits are received.
- [Create a new external financial institution](https://docs.brale.xyz/api-reference/brale/create-financial-institution.md): Links an external bank account to the specified account (ACH, wire, etc.).
- [Create a new internal address](https://docs.brale.xyz/api-reference/brale/create-internal-address.md): Provision an additional custodial (internal) address for the specified account.
- [Create Plaid link token](https://docs.brale.xyz/api-reference/brale/create-plaid-link-token.md): Step 1 of the Plaid-linked bank account flow. Generates a Plaid Link token to launch the Plaid UI for connecting a bank account.
- [Create Token Burn](https://docs.brale.xyz/api-reference/brale/create-token-burn.md): Burn tokens from a source address. Only available for tokenization (self-attested) accounts.
- [Create Token Mint](https://docs.brale.xyz/api-reference/brale/create-token-mint.md): Mint new tokens into a destination address. Only available for tokenization (self-attested) accounts.
- [Create Token Transfer](https://docs.brale.xyz/api-reference/brale/create-token-transfer.md): Move tokens between custodial and external addresses. Only available for tokenization (self-attested) accounts.
- [Create a new transfer](https://docs.brale.xyz/api-reference/brale/create-transfer.md): Creates a new transfer using the specified source and destination details.
- [Create Webhook Subscription](https://docs.brale.xyz/api-reference/brale/create-webhook-subscription.md): Create a new webhook subscription under a Brale account.
- [Retrieve a customer account](https://docs.brale.xyz/api-reference/brale/get-account.md): Returns the details of a specific customer account, including KYB status.
- [Retrieve an address](https://docs.brale.xyz/api-reference/brale/get-address.md): Retrieves a single internal or external Address by `address_id`.
- [Fetch the balance of an internal (custodial) address for a specific token](https://docs.brale.xyz/api-reference/brale/get-address-balance.md): Returns balance data for a given address, chain, and token.   Provide `transfer_type` and `value_type` as query parameters.
- [Retrieve a single automation](https://docs.brale.xyz/api-reference/brale/get-automations.md): Returns details for a specific automation.
- [Fetch a specific financial institution](https://docs.brale.xyz/api-reference/brale/get-financial-institution.md): Retrieves details for the specified financial institution (bank account).
- [Get Token Burn](https://docs.brale.xyz/api-reference/brale/get-token-burn.md): Retrieve a single tokenization burn order by ID.
- [Get Token Mint](https://docs.brale.xyz/api-reference/brale/get-token-mint.md): Retrieve a single tokenization mint order by ID.
- [Get Token Transfer](https://docs.brale.xyz/api-reference/brale/get-token-transfer.md): Retrieve a single tokenization transfer by ID.
- [Retrieve a single transfer](https://docs.brale.xyz/api-reference/brale/get-transfer.md): Returns details for a specific transfer.
- [Get Webhook Subscription](https://docs.brale.xyz/api-reference/brale/get-webhook-subscription.md): Retrieve a single webhook subscription by ID.
- [Link Verification Documents](https://docs.brale.xyz/api-reference/brale/link-verification-documents.md): Link staged KYB document submissions to an account.
- [Retrieve all accounts](https://docs.brale.xyz/api-reference/brale/list-accounts.md): Retrieve your client account and any managed accounts, returning account IDs, names, and KYB status.
- [Fetch all addresses](https://docs.brale.xyz/api-reference/brale/list-addresses.md): Retrieves all addresses (internal and external) associated with the given account.
- [Fetch all automations for an account](https://docs.brale.xyz/api-reference/brale/list-automations.md): Retrieves all automations associated with the specified customer account.
- [Fetch all financial institutions](https://docs.brale.xyz/api-reference/brale/list-financial-institutions.md): Returns all financial institutions associated with the given account.
- [List Token Burns](https://docs.brale.xyz/api-reference/brale/list-token-burns.md): List tokenization burn orders for an account.
- [List Token Mints](https://docs.brale.xyz/api-reference/brale/list-token-mints.md): List tokenization mint orders for an account.
- [List Token Transfers](https://docs.brale.xyz/api-reference/brale/list-token-transfers.md): List tokenization transfers for an account.
- [List transfers](https://docs.brale.xyz/api-reference/brale/list-transfers.md): Returns a paginated list of transfers for a given account, with optional filters.
- [List Verification Documents](https://docs.brale.xyz/api-reference/brale/list-verification-documents.md): List required KYB/KYC documents and their upload status for an account.
- [List Webhook Delivery Attempts](https://docs.brale.xyz/api-reference/brale/list-webhook-delivery-attempts.md): List webhook delivery attempts for debugging delivery status, retries, and failures.
- [List Webhook Event Types](https://docs.brale.xyz/api-reference/brale/list-webhook-event-types.md): Discover the webhook event types supported by Brale for a given account.
- [List Webhook Subscriptions](https://docs.brale.xyz/api-reference/brale/list-webhook-subscriptions.md): List the webhook subscriptions registered under a Brale account.
- [Register financial institution account via Plaid and return address ID](https://docs.brale.xyz/api-reference/brale/register-financial-institution-account-via-plaid-and-return-address-id.md): Completes the Plaid-linked bank account flow by exchanging a Plaid public_token and returning the new address_id.
- [Stage a Verification Document](https://docs.brale.xyz/api-reference/brale/stage-verification-document.md): Upload a KYB/KYC document for later linking to an account.
- [Update an Address](https://docs.brale.xyz/api-reference/brale/update-address.md): Update the name, status, or transfer types for an existing address.
- [Update Webhook Subscription](https://docs.brale.xyz/api-reference/brale/update-webhook-subscription.md): Update the URL or subscribed event types for an active webhook subscription.

- [Value Types](https://docs.brale.xyz/coverage/value-types.md): Canonical `value_type` identifiers for Brale transfers (onchain and offchain).
